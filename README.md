# Financial Manager — Releases

Public downloads for **Financial Manager** (מנהל הפיננסי שלי), an on-device personal‑finance app that brings your Israeli bank accounts, credit cards, pension/insurance (Har HaKesef / Har HaBituach), payslips and Bank of Israel credit data together — encrypted, on your phone.

The app source code is private; this repo hosts only signed release builds and their notes.

## Download & install
1. Open the [latest release](../../releases/latest).
2. Download the `.apk` asset.
3. On your Android phone, open the file and allow installing from this source if prompted.

> Prefer the Play Store? The app is in closed testing — ask the developer for a tester invite.

## Privacy
All data stays on your device, encrypted at rest. See the [privacy policy](https://gist.github.com/Igalbogus/e65731e109c79debf5f5b0209b14e10f).
